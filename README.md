# 方寸 · Cube Tutor

面向零基础新手的三阶魔方互动教学单页应用。Vite + Three.js，纯前端，无需账号或后端。

## 本地运行

```sh
npm install
npm run dev
```

打开终端输出的本地地址。生产构建使用 `npm run build`，结果位于 `dist/`。`npm test` 验证转动模型与公式可逆性。

## 功能

- 基础认知与七步层先法课程，提供说明、动作公式、目标和观察提示。
- 26 块三维魔方，支持六面、逆转、半转、自由视角和缩放。
- 动画播放、暂停、前进、回退、重置、公式定位与 0.5× / 1× / 1.5× 速度。
- 跟练时逐步检查输入，错误提示与移动端震动；半转按两次对应字母。
- 自由练习、22 步随机打乱、复原态重置、目标层聚焦和转动提示。
- 本地保存当前章节与手动标记的学习进度，桌面和移动端自适应。

键盘：`U D L R F B` 转动，`Shift + 字母` 逆转，空格播放暂停，左右箭头逐步前进后退。

本应用提供选定局面的教学演示与公式跟练，不包含任意打乱局面的自动求解器。聚焦功能按章节突出目标角块或棱块；箭头随当前转动面更新，以文字与实际层动画为准。
